# CAMRA-ON-EYE 👁️
### Hikvision AI Intelligent Surveillance & Security Matrix (V18.1)

نظام متكامل للمراقبة الأمنية والتحليل الذكي فائق الدقة (4K) لكاميرات وأجهزة تسجيل Hikvision (NVR / IP Cameras)، مدعوم بنماذج YOLO11 وتقنية قراءة لوحات المركبات (Fast-ALPR) مع إشعارات فورية عبر Telegram وتأكيد بالذكاء الاصطناعي (Gemini).

---

## 🌟 المميزات الرئيسية

- **بث WebRTC مباشر فائق السرعة:** زمن استجابة منخفض جداً (<0.5 ثانية) عبر محرك `go2rtc` المدمج.
- **تسجيل 4K مستمر (24/7):** تسجيل مباشر عالي الدقة بدون إعادة ترميز (`-c copy`) مع استهلاك 0% من طاقة المعالج.
- **تحليل الرؤية الذكي (YOLO11):** كشف وتتبع الأشخاص، المركبات (سيارات، شاحنات، دراجات)، والحيوانات في الزمن الفعلي.
- **قراءة لوحات المركبات (ANPR / LPR):** استخراج وقص لوحات السيارات بدقة 4K وتأكيد النص تلقائياً عبر `Fast-ALPR`.
- **مناطق الكشف وخطوط العبور:** رسم وتحديد مناطق الاهتمام (Zones) وخطوط العبور (Tripwires) ومناطق الاستبعاد (Masks).
- **إشعارات متعددة الوسائط (Telegram):** إرسال صور عالية الدقة ومقاطع فيديو MP4 ومعلومات اللوحة فور وقوع الحدث.
- **حماية الموارد الذاتية (Load Guard):** مراقبة استهلاك CPU/GPU في الزمن الفعلي والتحكم الذكي بمعدل المعالجة لمنع الاختناق.

## 🚀 التثبيت والتشغيل السريع

### 1. المتطلبات
- **Windows 10 / 11** (64-bit).
- **Python 3.10+** (مفعل معه خيار `Add Python to PATH`).
- مسرّع رسومي NVIDIA (مستحسن) أو معالج متعدد الأنوية.

### 2. تثبيت المتطلبات بنقرة واحدة
شغّل السكربت:
```cmd
INSTALL_DEPENDENCIES.cmd
```
أو عبر الطرفية:
```bash
pip install -r requirements.txt
```

### 3. التحقق من جاهزية النظام
```cmd
CHECK_SYSTEM.cmd
```

### 4. التشغيل المباشر
- **وضع التشغيل الكامل مع الكاميرات:**
  ```cmd
  START_LIVE.cmd
  ```
- **وضع المعاينة وتجربة الواجهة:**
  ```cmd
  START_PREVIEW.cmd
  ```
افتح المتصفح على: `http://127.0.0.1:5051`

## ⚙️ ضبط الكاميرا
1. انسخ ملف `config.example.json` إلى `config.json` أو اضبط الإعدادات مباشرة من واجهة الويب.
2. حدد عنوان IP الكاميرا/المسجل واسم المستخدم وكلمة المرور ورقم القناة.
3. اختر دقة البث ودقة الكشف (Main Stream 4K مستحسن).
